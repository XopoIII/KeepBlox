Every library runs unmodified in the same simulator, against the same fakes of DataStore, MemoryStore,
MessagingService and the engine, with the same players, faults and seeds. The table below is
`bench/Benchmarks.md` as the last `luneblox run bench/Report 20` wrote it; the methodology at its end
explains every column. To run it yourself:

```sh
luneblox run bench/download       # the rivals, at their pinned versions
luneblox run bench/Report 20      # every scenario over seeds 1-20, then the cost
```

These are simulator figures. The KeepBlox rows did not change when the benchmarks were re-measured on
2026-09-30 with the budget model measured live. On Roblox's real services calls take 0.3-0.6 s each, so
hand-overs (4.2-4.6 s against 3.2 s) and crash takeovers (11.6-12.9 s against 9.1 s) are slower. The
*No library* row is a game's own `GetAsync` / `SetAsync` code, as the Roblox guides teach.
